# 2026-08-13 工作日志

## 报销记录系统搭建

- 在 `D:\DDD\xxx\yt\ReimburseSystem` 下实现了完整的报销记录管理系统
- 技术栈：Vue 3 + Element Plus + Vite（前端）/ Go + Gin + GORM + MySQL（后端）
- 数据模型：三张表 `reimbursements`（主表）+ `reimbursement_persons`（人员分配，含审批单号/金额/状态）+ `reimbursement_reasons`（报销缘由，支持多项）
- 功能：新增/编辑/删除/查看报销记录，多人报销金额分配，报销缘由多选（交通/ETC/油费/误餐等），状态管理（待报销/已到账），整体+单人独立状态，统计面板，筛选查询
- 后端端口 8080，前端端口 5173，Vite 已配置 /api 代理
- 数据库配置通过环境变量，默认 root:root@127.0.0.1:3306/reimburse_system
- GORM AutoMigrate 自动建表，也提供了 init.sql 手动初始化脚本
